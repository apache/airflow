Ray connection
==============

Create a connection with connection type ``Ray``. Set ``Ray dashboard URL`` when using an existing
cluster. To manage KubeRay clusters, configure either a kubeconfig path or kubeconfig JSON, plus the
namespace and optional cluster context.
