Add "force run" for task instances. A new ``ignore_upstream_deps`` flag on the ``clearTaskInstances`` API and a **Force run (ignore upstream dependencies)** checkbox in the UI clear dialog re-run a task instance even when the task instances it depends on have not succeeded (trigger rule, branch and ``ShortCircuitOperator`` skips, ``depends_on_past``, ``wait_for_downstream``, mapped upstream). Retry delay, sensor reschedule interval, pools, concurrency limits and paused Dags still apply. The flag is stored on the task instance, recorded per try in task instance history, and reset by the next clear.
