Plugin external views and React apps can be scoped to specific Dags and tasks with an optional ``applies_to`` block accepting ``dag_tags``, ``dag_ids``, ``task_ids``, ``operators``, and ``operator_names``, so a tab or panel is only shown where it is relevant instead of on every Dag. Criteria are combined with OR within a key and AND across keys, evaluated only against the keys the current page can judge; omitting ``applies_to`` shows the item everywhere, which is the previous behaviour. This gates the tab affordance only and is not an authorization boundary. See :doc:`the plugins documentation </administration-and-deployment/plugins>` for details.
