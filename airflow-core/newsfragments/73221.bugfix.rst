The default task failure email no longer dumps every field of the task instance. Its subject now reads ``[Airflow] <dag_id>.<task_id> <state> - Run <run_id>`` and its body names the Dag, the task, the run and the timestamps. ``{{ ti }}`` — which the old default subject rendered, and which templates carried over from Airflow 2 still use — now renders the compact ``<TaskInstance: dag_id.task_id run_id [state] ti_id=...>`` form used elsewhere in Airflow.
