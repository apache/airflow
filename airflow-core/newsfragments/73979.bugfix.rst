Fix the Dag processor treating callback processors for Dags packaged inside zip archives as orphaned on every bundle refresh. The scanner reports the archive as a single entry while callback processors are keyed by the Dag file path inside it, so the presence check saw the inner path as missing and SIGKILLed the processor, and the queue purge and file-stats cleanup dropped the Dag each refresh too. A path inside a zip now counts as present while its containing archive is in the scan set.
