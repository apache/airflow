Plugin external views and React apps can be scoped with an optional ``applies_to`` block, a map of dotted field path to the values that path may take, such as ``{"state": ["failed"], "dag.tags.name": ["ml"]}``. This replaces the five fixed criteria added earlier in this development cycle and never released (``dag_tags``, ``dag_ids``, ``task_ids``, ``operators``, ``operator_names``). A path naming a field no record has is treated as a misconfiguration rather than a filter that never matches, so the view is not loaded and the reason is logged. See :doc:`the plugins documentation </administration-and-deployment/plugins>` for the path syntax, the migration table and the trade-offs.
