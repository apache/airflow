The Dag details breadcrumb now doubles as a Dag switcher: the first level names the current Dag and a chevron beside it opens the Dag search in place, replacing the separate search button that sat next to the breadcrumb. The ``mod+k`` shortcut opens this switcher. The pause toggle has moved out of the breadcrumb to sit with the other Dag actions in the page header, where it is available on every Dag page rather than only on deeper ones.
