Fix asset-triggered tasks failing before they start for workers running Task SDK 1.2.x (Airflow 3.2.x), which request execution API version ``2026-04-06``. Those workers received a ``partition_key`` field on the Dag run's consumed asset events that their models reject, raising an ``extra_forbidden`` validation error. The field is now gated behind version ``2026-06-30``, where it was introduced; workers on ``2026-06-30`` or newer are unaffected.
