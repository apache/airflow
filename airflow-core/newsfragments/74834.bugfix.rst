Reject Dag run ``conf`` holding reserved serialization keys such as ``__classname__`` or ``__type``, as XCom and Human-in-the-loop values already do. The trigger Dag run, materialize asset and create backfill endpoints, and the Execution API trigger Dag run endpoint, now return 422 for such a payload; string values in ``conf`` are not inspected. A Deadline Alert ``AsyncCallback`` whose context still holds these keys is marked failed instead of queued, and the scheduler moves on to other deadlines instead of stopping.
