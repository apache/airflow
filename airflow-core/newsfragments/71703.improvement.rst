Dags placed in sub-folders of a packaged (zip) Dag bundle are now discovered, as long as the sub-folder and every folder above it is an importable package (contains an ``__init__.py``). Previously only Dags at the archive root were imported and sub-folder Dags were silently skipped. A Dag file in a non-package sub-folder still cannot be imported from a zip, but it is now skipped with a warning naming the unreachable file instead of being dropped silently.
