# Italian translations

The Italian interface keeps familiar Airflow terms such as `Dag`, `Task`,
`XCom`, `Asset` and `Pool` in English so they remain recognizable alongside
code and documentation. Interface actions and general concepts use Italian,
including `Elimina`, `Salva`, `Connessione` and `Variabile`.

Use Italian grammar around technical names, such as `del Dag` and
`della connessione`. Existing strings include older wording; consult the
[Italian translation guidelines](../../../../../../../../.agents/skills/airflow-translations/locales/it.md)
for the glossary, plural forms and the Italian translation owner's corrections
from earlier reviews.
